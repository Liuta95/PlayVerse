# PlayVerse foundations

Tokens come from the **Game-PlayVerse** Figma Variables into `src/tokens/tokens.json` (W3C DTCG, 351 tokens).
`npm run tokens` generates `src/tokens/tokens.css` from it. Never edit either file by hand: update the Variables in Figma and re-export.

Three levels, each one refers to the level above it:

1. **Primitives** (Figma collection `Primitives`) → `color.<hue>.<step>` → `--color-gray-900`. Raw colours, no meaning.
2. **Semantic** (Figma collection `Semantic`, plus the older `text`, `background`, `stroke`, `icon` groups that still live in `Component Colors`) → `--action-primary`, `--content-muted`, `--surface-field`, `--border-strong`, `--feedback-success-bg`. What a colour is *for*.
3. **Component** (Figma collection `Component Colors`) → `--buttons-primary-default-background`, `--chips-success-bg`, `--inputs-stroke-active`. One detail of one component.

Example chain: `--buttons-primary-default-background` → `--action-primary` → `--color-purple-700` → `#6d28d9`.

Spacing, radius and typography have their own collections: `--spacing-16`, `--radius-12`, `--font-size-14`, `--line-height-relaxed`.

In components use the component token, or the semantic one when there is no component token. Primitives only as a last resort. `checkboxes`, `coins`, `app-bars`, `BottomNavBar` and `Alert` tokens still point straight at primitives (they have not been moved to the semantic level yet).

## Typography

Families are token values (`Space Grotesk`, `Manrope`, `Inter`). **Space Grotesk** (display) and **Manrope** (body) are bundled through `@fontsource` in `src/styles/fonts.css` (Latin, weights 400 / 600 / 700). **Inter** exists as a token but is not bundled, so its specimen renders in a system fallback.

## Notes on the export

- `line-height.*` is stored in Figma as `150` / `160` (percent). It is exported as `150%` / `160%` so the CSS is valid.
- `letter-spacing.*` is exported in `px` (Figma variable descriptions say `0.3px`, `0.72px`, `0.78px`).
- Semi-transparent colours are 8-digit hex (`#8b5cf624`). Variable names with spaces or brackets are sanitised: `purple/500 (14%)` becomes `purple.500-14pct`, `green/400 2` becomes `green.400-2`.
